Überschlagen, dann mit Wurzeln lösen

Aufgabe: Überschlage zuerst ohne Taschenrechner. Gib anschließend die Lösungsmenge mithilfe von Wurzeln an.

a) x² = 125b) x² = 200c) x² = 486d) x² = 1211

So gehst du vor

  1. Überschlagen: Suche die zwei Quadratzahlen, zwischen denen die Zahl liegt. Dann liegt die Wurzel zwischen deren Wurzeln. Beispiel: 121 < 125 < 144, also 11 < √125 < 12.
  2. Teilweise radizieren: Zerlege den Radikanden in größte Quadratzahl · Rest und ziehe aus der Quadratzahl die Wurzel: √125 = √25·5 = 5√5.
  3. Lösungsmenge: x² = c mit c > 0 hat zwei Lösungen, weil auch (−x)² = x² gilt. Also L = {−√c; √c}. Für c = 0 gibt es nur x = 0, für c < 0 keine Lösung: L = { }.
Quadratzahlen zum Nachschlagen (auswendig lernen lohnt sich)

Die Lösungen Schritt für Schritt

Wähle eine Teilaufgabe. Mit „Nächster Schritt“ deckst du die Lösung nach und nach auf. Versuch es zuerst selbst.

Alle Ergebnisse auf einen Blick

a) 11 < √125 < 12 (≈ 11,2)  → L = {−5√5; 5√5}
b) 14 < √200 < 15 (≈ 14,1)  → L = {−10√2; 10√2}
c) 22 < √486 < 23 (≈ 22,0)  → L = {−9√6; 9√6}
d) 1 < √(12/11) < 1,1 (≈ 1,04) → L = {−2√33/11; 2√33/11}  bzw. {−√(12/11); √(12/11)}

Wurzel-Werkstatt: eigene Beispiele

Gib eine rechte Seite für x² = … ein: eine ganze Zahl (z. B. 72), einen Bruch (z. B. 5/27) oder eine Dezimalzahl (z. B. 2,5). Die Werkstatt rechnet dieselben drei Schritte vor.

Übung: Du bist dran

Neue Gleichung, gleiche Fragen. Trage die beiden ganzen Zahlen für den Überschlag ein und schreibe die positive Lösung als a√b.

Richtig: 0 von 0

Typische Fehler

Die negative Lösung vergessen

L = {5√5}L = {−5√5; 5√5}(−5√5)² = 25 · 5 = 125. Die negative Zahl löst die Gleichung auch.

Nicht die größte Quadratzahl

√200 = √(4·50) = 2√50√200 = √(100·2) = 10√2Unter der Wurzel darf am Ende kein Quadratfaktor mehr stecken. 50 = 25 · 2 geht noch weiter.

Durch 2 statt Wurzel

x² = 200 → x = 100x = ±√200 ≈ ±14,1Probe: 100² = 10 000, nicht 200. Der Überschlag deckt solche Fehler sofort auf.
